# Xeonis Website

Kompakte Landingpage fuer die HTL 3 Rennweg Diplomarbeit **Xeonis**.

## Inhalt
- `index.html`: Startseite mit Hero, Projektzielen, Rackplan (3D) und Hardware-Section
- `team.html`: Teamvorstellung
- `impressum-kontakt.html`: Impressum und Kontakt
- `css/style.css`: Gesamtes Styling (inkl. responsive Regeln)
- `js/main.js`: Mobile Navigation + Reveal-Animation
- `css/rack.css`, `js/rack.js`: drehbares 3D-Rack (reines CSS 3D, ohne Bibliothek), jedes Gerät als Körper mit eigener Tiefe. Die Geräte stehen im Array `DEVICES` in `js/rack.js` (Name, Rolle, Höheneinheiten, Tiefe in mm; die Tiefen sind geschätzt und gehören nachgemessen), die Rack-Maße in `css/rack.css`
- `assets/rack/`: Vorder- und Rückseite des Racks aus dem Rackplan (`Xeonis_Rackplan_TOFT_Vorder_Rückseite.pdf`), freigestellt und pixelgleich als verlustfreies WebP
- `assets/`: Bilder und Logos
